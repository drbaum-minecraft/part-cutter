## Hosting

GitHub Pages publishes the `main` branch, `/ (root)`. The page is self-contained in `privacy/index.html`; `.nojekyll` disables Jekyll. No npm build, external assets, fonts, analytics, cookies or credentials are needed. Both language versions remain available when JavaScript is disabled.

This public repository contains the website only. Android source code, APKs, signing files and private configuration are not part of this repository.

## Policy scope

Reviewed against the current **Beta 1.0, build 14** release on **2026-10-04**. Ads and actual Play purchases are unconfigured in this release, despite the bundled Google SDKs. Update the policy before activating monetization or changing data practices. The Google Play Data safety form must be assessed independently against the final uploaded build.
